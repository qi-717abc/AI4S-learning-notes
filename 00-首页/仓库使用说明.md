# 仓库使用说明

## 打开仓库

在 Obsidian 中选择“打开文件夹作为仓库”，选择 `Q:\codexx\DM ppt\AI4S学习笔记`，然后打开 [[首页]]。文件是普通 Markdown，也可以用其他编辑器查看。

## 如何开始学习

把第一份课程 PPT 提供给 Codex，并说明希望整理的范围。Codex 会先检查能否读取，再根据课件建立课程笔记；需要补充时检索资料并注明来源。整理完后从 [[学习进度]] 和 [[首页]] 进入相关笔记。若文件路径、页码或图表无法读取，应先解决读取问题，不能根据标题猜测内容。

| 目录 | 用途 |
| --- | --- |
| `00-首页` | 入口和使用说明 |
| `01-课程笔记` | 按课程实际顺序整理的笔记 |
| `课程原始资料` | 保存用户提供的课程 PDF 等原始材料 |
| `02-核心概念` | 可跨课程复用的概念 |
| `03-专题与方向` | 根据学习逐步形成的专题 |
| `04-文献阅读` | 论文及其他资料的阅读记录 |
| `05-问题与复习` | 学习进度、问题和复习 |
| `90-模板` | 课程、概念和文献模板 |

创建课程笔记时可复制 [[课程笔记模板]]，建议命名为 `01-课程名称`、`02-课程名称`，以实际学习顺序编号。其他笔记按主题命名即可。先有内容、再建链接；不需要预先填满所有目录。

## Copilot 与 GitHub

在已安装并完成必要配置的 Obsidian Copilot 中，可复制 [[Copilot学习提示词]] 使用；具体的模型、密钥、索引和笔记访问范围取决于插件配置。本仓库不会自动配置这些功能，也不能保证 Copilot 自动读取 [[AGENTS]]。

GitHub 同步尚未配置。需要同步时，先确认 Git 仓库、远程地址和准备上传的文件；每次提交或推送前由你确认具体变更。原始课件和个人资料不会默认上传。
